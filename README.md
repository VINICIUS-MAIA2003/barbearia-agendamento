# 💈 Barbearia Clássica - Sistema de Agendamento

Um site simples, moderno e responsivo desenvolvido para facilitar o agendamento online de horários em uma barbearia.

🔗 **[Clique aqui para acessar o site online](https://seu-usuario.github.io/barbearia-agendamento/)**

---

## ✨ Funcionalidades

- **Seleção de Serviços:** Escolha entre corte, barba, combo ou sobrancelha com valores exibidos.
- **Escolha de Profissional:** Opção para selecionar um barbeiro específico ou deixar sem preferência.
- **Validação de Data:** Bloqueio automático de datas passadas no calendário.
- **Feedback Instantâneo:** Confirmação visual na tela com o resumo completo do agendamento.
- **Design Responsivo:** Interface adaptada para celulares, tablets e computadores.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica do formulário e da página.
- **CSS3:** Estilização temática (dark mode com detalhes em dourado) e responsividade.
- **JavaScript:** Manipulação do DOM, validação de datas e exibição dinâmica da confirmação.
